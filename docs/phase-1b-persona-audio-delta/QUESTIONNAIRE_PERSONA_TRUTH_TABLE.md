# Questionnaire/persona truth table

The rule version is `2026-07-29-v1`. Q1 values are `rarely`, `monthly`, `weekly`, `almost_nightly`; Q2 values are `shake_it_off`, `awake_scared`, `too_frightened_to_close_eyes`; Q3 values are `beside_me`, `not_always_present`, `alone`.

When Q1 is weekly/almost-nightly and Q2 is awake-scared/too-frightened, Q3 yields the matching frequent/intense persona. The twelve matching combinations divide 4/4/4 among beside-user/not-always-present/alone; the other 24 complete combinations are `general_default`. An incomplete draft has no persona.
