# Architecture and data boundary

`questionnaire_drafts` is local-only, nullable only for incomplete answers, and account/profile-bound. `persona_answer_aggregates` is the one complete current answer set; its persona is deterministically derived in Swift and generated by PostgreSQL. Personal audio uses local metadata only: no bytes, name, path, transcript, waveform, embedding, URL, remote ID, bucket, or payload is represented.

The production payload provider accepts only a complete aggregate for the matching authenticated account. It rejects draft and audio entity types by omission from the type system and operation matrix. Onboarding does not start sync.
